## Independent explorer verification

`python scripts/verify_explorer_txs.py` re-queried every hash above through the official
Studio explorer JSON API (`https://explorer-studio.genlayer.com/api/transactions/{h}`) and compared the lifecycle status,
leader execution result and validator vote tally with the RPC receipt the driver recorded.

- transactions resolved: 37 (35 contract calls, 2 plain value transfers), all FINALIZED: true
- mismatches: none
- consensus evaluations carrying an equivalence-principle output group: evaluate-drift, reevaluate-crispr
- gated attempts that reverted, leaving the contract state hash unchanged: gate-evaluate-too-early, author-response-wrong-caller, settle-too-early

The explorer serves no source code for studionet contracts, so source identity is proven
by `scripts/verify_source_identity.mjs`: local file, git blob, GitHub raw and the code the
RPC returns for the deployed address must all hash to the same SHA-256.
